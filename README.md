# ATI-Normandy — flooded roads and commuting: input data maps (prototype)

Interactive maps of the open data used in the flooded-roads calculation of the ATI-Normandy project.

- `index.html` — Normandy: the eight flood-risk areas (TRI), flood surfaces by type, motorways and national roads
- `caen.html` — Caen: the seven TRI flood maps, BD TOPO roads and buildings

Sources: TRI flood maps (DREAL / Géorisques, 2020 release); IGN BD TOPO 3.5 (2025 release); IGN ADMIN EXPRESS (2026 release); INSEE census 2023 (2026 release). Base maps: IGN Géoplateforme, Esri.
All sources are open data (Licence Ouverte / Etalab 2.0). Prototype, October 2026 — Seon Ju Lee, CREM, Université de Caen Normandie.
